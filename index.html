AI는 아래 명령 규격으로 픽셀을 그립니다. 사람이 그린 그림 위에 이어서 작업할 수도 있어요.

CANVAS API v1.0
setPixelfillRectdrawLinefillPolygon

픽셀 좌표는 0–127 정수입니다. 사각형 영역은 캔버스 경계에서 잘립니다.

실행 전 미리보기에서 명령을 확인합니다.

명령 형식미니 가이드
// 한 픽셀 지정
{ "op": "setPixel", "x": 64, "y": 64,
  "color": "#e28a5b" }
// 여러 작업을 순서대로
[
  { "op": "fillRect", "x": 40, "y": 40,
    "width": 48, "height": 48, "color": "#e28a5b" },
  { "op": "fillPolygon", "points": [[64,20],
    [100,58], [28,58]], "color": "#273b3a" }
]
