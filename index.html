AI는 아래 명령 규격으로 픽셀을 그립니다. 사람이 그린 그림 위에 이어서 작업할 수도 있어요.

PIXEL STUDIO JSON v1.1
settingssetPixelfillRectfillPolygon

설정과 명령을 한 JSON 문서로 적용합니다. 좌표 범위는 현재 캔버스 크기를 따릅니다.

실행 전 미리보기에서 명령을 확인합니다.

명령 형식미니 가이드
// 프로젝트 전체 저장 형식
{ "format": "pixel-studio-project", "version": 1,
  "settings": { "canvas": { "width": 128,
    "height": 128 } }, "pixels": { ... } }
// 설정 + AI 그리기 명령
{ "format": "pixel-studio-commands", "version": 1,
  "settings": { "preset": "fine256",
    "canvas": { "width": 256, "height": 256 } },
  "commands": [{ "op": "setPixel", "x": 64,
    "y": 64, "color": "#e28a5b" }] }
